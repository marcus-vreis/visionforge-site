- `classification-dark.webp`, `classification-light.webp` and their `classification-en-*` equivalents: screenshots of the real VisionForge v0.20.1 GUI, recaptured on 2026-11-03, 1440 × 1000. The source checkout of the recapture was not recorded; they were not recaptured for 0.21.0. Captured using an isolated empty workspace and a fresh browser context with the demonstration name “Researcher”. No training was started and no personal dataset or result was used. WebP encoding only; no UI reconstruction or fabricated values.
- `social.png`: website-specific typographic composition derived from its branding; not a product screenshot or experiment result.
- `favicon.svg`: original simplified crosshair mark based on the product header's circular mark; the frontend starter favicon was not reused.
- `replicates-pt-dark.webp`: `docs/images/vf-replicates.png` from the product's `development` branch (generated by its `scripts/capture_docs_images.py` at commit `b82ce7a`, version 0.21.0, 2026-11-11, 1440 × 960, temporary workspace, `--offline`, no GPU, dark theme, pt-BR). WebP encoding only. Shows the Strategy step with Replicates on; no training was run. There is no light or English capture, and the caption says so.
- Replicas diagram (`src/components/Replicas.astro`): original animated inline SVG, labelled as an illustration; bar lengths and dot positions are arbitrary and represent no experiment.
- Terminal session in the opening: commands and output endings quoted from the product's `docs/INSTALL.md` at v0.21.0 (`environment looks good`, `5/5 cases passed`, `http://127.0.0.1:8000`); it is text, not a recording.
- `code-tab-pt-dark.webp`: `docs/images/vf-code-tab.png` from the same script run, cropped to the dialog (box 340, 84, 1100, 876 → 760 × 792) to drop the blurred backdrop, then WebP-encoded. It shows the Code tab after one CPU epoch, a feature of the development branch that is marked "from 0.22" on the page.
- Fonts: IBM Plex Sans and IBM Plex Mono from pinned Fontsource packages. SIL OFL license notices are included under `public/licenses/`.

The English variants were captured after switching the application's own PT/EN control; the light variants use its own theme control.

- `custom-task-dark.webp`, `custom-task-light.webp` and `custom-task-en-*`: actual v0.20.1 GUI recaptured on 2026-11-03, 1440 × 1100. The source checkout of the recapture was not recorded. Isolated workspace contains the downloadable `research_method.py` in `user_tasks/`; generated form shows `research_weight`, `n_samples=32`, `epochs=1`, `batch_size=8` and CPU selected. Demonstration name “Researcher”, experiment `tutorial_cpu`. No personal paths, datasets or experiment results are shown. Training was separately verified in a temporary directory on CPU.
- `public/examples/research_method.py`: adapted from VisionForge v0.17.0's MIT-licensed `tasks/scaffold.py`, adding a Pydantic field, an illustrative parameter penalty and sample-weighted MAE aggregation. The synthetic data and model are educational examples.
- `public/examples/research_cnn.py`: small RGB model built with PyTorch and the existing `register_model` decorator. The guide imports this exact file as text to avoid divergence between displayed and downloadable code.
