# Asset provenance

- `public/images/guias/`: the screenshots cited by the three entry guides, taken unchanged from `docs/images/` of the product at tag `v0.22.0` by `scripts/guide_images.py` (it downloads them from the tagged repository) on 2026-11-15 (1440 × 960 px PNG converted to WebP quality 88, no crop or retouching). They are the product's own documentation captures: Portuguese interface, dark theme, demonstration name “Researcher”, the application's synthetic sample dataset. `vf-training-film.gif` (640 × 427 px, 36 frames) is the product's recording of an eight-epoch run on that dataset, copied byte for byte; `vf-training-film-still.webp` is its first frame, shown to readers who ask for reduced motion. `vf-learn-curves` is an illustrative figure of the application, as its guide says.
- `src/content/guias/pt/*.md`: byte-for-byte copies of `docs/guias/` at `v0.22.0`. `src/content/guias/en/*.md`: translations made for this site; interface labels are the ones in `frontend/src/i18n/en.ts` at that tag.

- Captures taken on 2026-11-14 from the product's `development` branch at `b5ae08a` (version string 0.21.0, hidden in the header of every capture), running `visionforge gui` from the workspace `C:\vf-demo` with an isolated user folder, demonstration name “Researcher”. Chromium 1280 × 920 CSS px at device scale factor 2, so each file is 2560 × 1840 px; WebP quality 88, no retouching. Languages and themes were switched with the application's own controls. The script (`.capture/gui-capture.mjs`, not versioned) also read the bounding boxes used for the target positions in `src/content/figures.ts`.
  - `classification-{dark,light}.webp` and `classification-en-*`: Data step of classification after “use the sample dataset”. No training was started.
  - `custom-task-{dark,light}.webp` and `custom-task-en-*`: the downloadable `research_method.py` in `user_tasks/`, Training step. Synthetic task, no result shown.
  - `replicates-{pt,en}-{dark,light}.webp`: regression, Strategy step with Replicates selected, retaken the same day at `5e3bcba` (the "When to use" line under the selector). No dataset, no training.
  - `colab-{pt,en}-{dark,light}.webp`: the Colab corner open, no CLI installed and no Google account; cropped to the header and the pop-over (CSS box 60, 0, 960, 290 → 1800 × 580 px).
  - `code-tab-{pt,en}-{dark,light}.webp`: the Live code tab of the training screen at the Training epoch step, after a classification run of one epoch on the application's synthetic sample dataset (random initialisation, experiment name `site_demo`); cropped to the training sheet (CSS box 92, 54, 1188, 866 → 2192 × 1624 px). The machine's GPU was used for that run, which took about three seconds. No metric of the run is shown on the site.
- `social.png` and `social-en.png`: link-preview images, 1200 × 630 px, rendered on 2026-11-14 by `scripts/social-image.mjs` from the hero title in `src/content/{pt,en}.ts`, the site's IBM Plex fonts and the dark-theme tokens. The terminal lines are the commands and the address of the installation guide. Typographic compositions, not product screenshots or experiment results.
- `favicon.svg`: original simplified crosshair mark based on the product header's circular mark; the frontend starter favicon was not reused.
- `src/content/runjson.ts`: lines of a real `run.json` written on 2026-11-12 by `visionforge run` for the digits case of the guides (120 images, 1 epoch, CPU, same checkout). Folded objects are shown as `{ … }`, and the start of `run_dir` is replaced by `…`; no value is altered. Its metrics are folded on purpose.
- Interface replica (`Studio.astro`, `src/content/studio.ts`): original HTML and CSS, not a capture. Labels, colours, steps, strategies, models and defaults were read from the product's frontend on the `development` branch at `5e3bcba` (2026-11-14) and `utils/*config.py`; it is labelled as a simplified demonstration and does not train.
- Task diagrams in the tasks table (`TaskGlyph.astro`): original animated inline SVG, decorative, in the application's task colours. The segmentation one is a generic person outline drawn for this site, not taken from any image.
- Code beside the form (`CodeForm.astro`): lines copied from `public/examples/research_method.py`; the form values are that file's defaults.
- Replicas diagram (`src/components/Replicas.astro`): original animated inline SVG, labelled as an illustration; bar lengths and dot positions are arbitrary and represent no experiment.
- Terminal session in the opening: commands and output endings quoted from the product's `docs/INSTALL.md` at v0.21.0 (`environment looks good`, `5/5 cases passed`, `http://127.0.0.1:8000`); it is text, not a recording.
- Fonts: IBM Plex Sans and IBM Plex Mono from pinned Fontsource packages. SIL OFL license notices are included under `public/licenses/`.

- `public/examples/research_method.py`: adapted from VisionForge v0.17.0's MIT-licensed `tasks/scaffold.py`, adding a Pydantic field, an illustrative parameter penalty and sample-weighted MAE aggregation. The synthetic data and model are educational examples.
- `public/examples/research_cnn.py`: small RGB model built with PyTorch and the existing `register_model` decorator. The guide imports this exact file as text to avoid divergence between displayed and downloadable code.
